# TatagMarinduque Project Manuscript and References

## Project concept

TatagMarinduque is a prototype concept for connecting the island's micro-enterprises with buyers and with local suppliers. Its core workflows are a searchable maker directory, a sample wholesale quote flow, and a sourcing board for materials makers need or can supply.

The current deliverable is a static HTML, CSS, and JavaScript demonstration. Its sample interactions are stored in the visitor's browser only. It does not provide real user accounts, secure authentication, server-side data, message delivery, official business verification, or a production marketplace.

## Prototype approach

The static conversion keeps the original concept and fictional example records while replacing the previous client/server stack with ordinary web files. Shared sample records live in `../data/demo-data.js`; pages are in `../html/`; and styles and behavior live in `../css/` and `../js/`. A generated local SVG replaces external product-image URLs.

The directory can be searched and filtered by category and sample verification status. Maker profiles link to a browser-only quote preview. Visitors can add sample sourcing posts, set up a local demo profile, and change sample review statuses. None of these actions transmit information or represent real transactions or official decisions.
